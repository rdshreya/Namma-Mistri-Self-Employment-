# Namma-Mistri-Self-Employment

## Project Overview
Namma-Mistri is an Android application developed using Kotlin and Jetpack Compose for construction material estimation and cost calculation.

## Features
- Material cost estimation
- User-friendly interface
- Fast calculations
- Construction planning support

## Technologies Used
- Kotlin
- Android Studio
- Jetpack Compose

## Installation
1. Clone the repository
2. Open in Android Studio
3. Sync Gradle
4. Run the application

## Project Structure
- src/ → source code
- assets/ → images and resources

## Future Improvements
- Add cloud storage
- Add user login
- Add PDF report generation
